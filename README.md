Flamingo Run is an endless runner game heavily based on the Google Chrome Dino game.

Using the pygame engine, I recreated it and made some additions including:
  - powerups (fireball, laser vision, boxing glove)
  - Character customisation (Only colour of character so far)
  - Theme options (Chrome dino, Mario, Minecraft)

Some art I found online but most I had to do myself in a pixle art creation web app.
